# Ananta France : mise en ligne

## 1. Avant de publier
- Ton domaine « ananta-france » n'est pas complet : j'ai utilisé `www.ananta-france.fr` comme exemple. Remplace-le si besoin dans `index.html` (balises canonical, og:url, og:image, JSON-LD), `sitemap.xml` et `robots.txt`.
- Ajoute une image `image-partage.jpg` (1200 x 630 px) à la racine du site pour l'aperçu sur les réseaux sociaux.
- Remplace le logo textuel par ton logo si tu veux (dans `.logo` de `index.html`).
- Tes couleurs : modifie les variables au début de `style.css` (`--cyan`, `--rose`, `--nuit`...).

## 2. Héberger gratuitement
### Netlify (le plus simple)
1. Va sur netlify.com et crée un compte.
2. Glisse le dossier `ananta-france` dans « Deploy manually ».
3. Dans « Domain management », ajoute ton nom de domaine.

### GitHub Pages
1. Crée un dépôt public sur GitHub et envoie les fichiers.
2. Settings > Pages > Deploy from a branch > main > / (root).
3. Ajoute ton domaine dans « Custom domain » et active HTTPS.

## 3. Indexer sur Google
1. Ouvre search.google.com/search-console et ajoute ta propriété.
2. Valide la propriété (balise DNS ou fichier HTML).
3. Sitemaps > ajoute `sitemap.xml`.
4. Inspection de l'URL > saisis ta page d'accueil > « Demander une indexation ».
5. Patiente quelques jours à quelques semaines.

## 4. Pour mieux ressortir
- Ajoute ton site dans ta description Discord, Disboard et Top.gg.
- Mets le lien du site dans les profils de tes réseaux sociaux.
- Publie des pages de guides sur Ananta : elles attirent du trafic sur des mots-clés précis.
- Mets à jour le nombre de membres et la date de sortie si elle change.
